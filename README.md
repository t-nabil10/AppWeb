# Suivi Heures & Revenus

Application web (PWA) de suivi des heures de travail et des revenus mensuels dans une école. Montants en MAD (DH).

- HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, Chart.js, SheetJS, jsPDF
- Données stockées dans le localStorage du navigateur (aucun serveur)
- Exports Excel / PDF, sauvegarde et restauration JSON

## Utilisation
Ouvrir `index.html`, ou héberger le dossier (GitHub Pages) pour installer l'application sur téléphone.

## Fichiers
`index.html`, `styles.css`, `app.js`, `manifest.json`, `sw.js`, `icons/`
